# 脚本蓝图（5 秒级模板）

## 通用结构

```
0-3s   钩子（反问 / 数字 / 痛点）
3-12s  主体 1：抛出答案（具体名词 + 证据）
12-20s 主体 2：分步讲解（3 步可截图）
20-26s 收尾：建议行动（手比心 / 划一下 / 提示收藏）
26-30s 黑场 / 弹幕贴纸
```

## 5 种话题骨架（拍摄者提问 + 学生回答）

**角色规则**：
- 0-3s 钩子 = **拍摄者 OS**（老师/采访者，画外音）
- 3-26s = **学生** 回答（默认戴银眼镜少年 A 为主答，B/C/D 补充）
- 拍摄者不出镜，只用字幕 + 旁白提问
- 学生必须先直接给答案，再分步，再收尾

### 4.1 入门型（知识库那种）

```
【0-3s 钩子】
拍摄者（OS）：使用 ___ 的第一步是干嘛？

【3-12s 主体 1】
少年 A：___。（具体名词）
少年 A：___ 。（一句话说清楚）

【12-20s 主体 2】
少年 B：先去 ___ 找，再选适合自己的。

【20-26s 收尾】
少年 C：___ 就够了，记得收藏。

【26-30s 黑场】
"是这样吗" 弹幕滚动
时长：25-30s
```

### 4.2 提示词型（AI 提示词那种）

```
【0-3s 钩子】
拍摄者（OS）：为啥你的 AI 总是答不对？

【3-12s 主体 1】
少年 A：不是 AI 不行，是提示词没写对。

【12-20s 主体 2】
少年 B：记住这 3 条——
少年 B：1. ___  2. ___  3. ___

【20-26s 收尾】
少年 C：直接抄过去就能用，评论区要模板。

【26-30s 黑场】
"是这样吗" 弹幕滚动
时长：30-40s
```

### 4.3 实测型（4 个少年干一件事）

```
【0-3s 钩子】
拍摄者（OS）：___ 到底能不能用？

【3-12s 主体 1】
少年 B：我来试 —— ___。

【12-20s 主体 2】
少年 C：卡在 ___ 这步。
少年 D：换成 ___ 就解决了。

【20-26s 收尾】
少年 A：结论：学生党够用了。

【26-30s 黑场】
"是这样吗" 弹幕滚动
时长：30-40s
```

### 4.4 痛点型（蹭学习场景）

```
【0-3s 钩子】
拍摄者（OS）：___ 课要交作业了，我只用 1 小时。

【3-12s 主体 1】
少年 B：拆成 30 秒可以做完的 5 步。

【12-20s 主体 2】
少年 C：1. ___  2. ___  3. ___  4. ___  5. ___

【20-26s 收尾】
少年 A：上 ___ 找灵感就够。

【26-30s 黑场】
"是这样吗" 弹幕滚动
时长：22-30s
```

### 4.5 避坑型（情绪 + 干货）

```
【0-3s 钩子】
拍摄者（OS）：___ 之前，先别做这 3 件事。

【3-12s 主体 1】
少年 B：坑 1：___

【12-20s 主体 2】
少年 C：坑 2：___
少年 D：坑 3：___

【20-26s 收尾】
少年 A：直接用我们的方案。

【26-30s 黑场】
"是这样吗" 弹幕滚动
时长：30-40s
```

## 标配

- 每条视频 = 4 个少年中至少 2 个轮换
- 每条视频 = 1 个电脑屏幕特写（证据）
- 每条视频 = 1 个贴纸收尾
- 每条视频 = 1 个可截图的步骤（招收藏）
- **0-3s 钩子固定 = 拍摄者 OS 提问，不让学生自问自答**
