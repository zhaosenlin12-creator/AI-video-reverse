# 算法保证 + 边界声明

## ✅ 工作流能 100% 保证的（确定性）

每次调用，下面这些是**确定会发生**的：

1. **实时扫描 5 个来源**（web_search），覆盖抖音 / 小红书 / AI 媒体 / X / GitHub
2. **每个来源做 2 轮搜索**：当下热门 + 上升趋势
3. **多来源同时提到 = 上升信号**（≥3 个来源提同一个话题 = 强上升）
4. **赛道过滤**：按 AI四小只 账号画像过滤（AI 工具 / 教程 / 校园）
5. **6 维度打分 × 0-3 分**，按总分降序
6. **总分 ≥ 12 分进选题池**（门槛提高，避免低分话题混入）
7. **爆款特征匹配**：和知识库 / 提示词爆款特征清单重合度打分
8. **类型覆盖**：入门型 / 实测型 / 提示词型 各 1 条
9. **排重**：和已有 7 条视频比较，重合度高的扣分
10. **脚本结构固定**：拍摄者 OS 提问 + 银眼镜少年 A 主答 + B/C/D 补充 + 手比心收尾

## ❌ 工作流不能保证的（边界）

1. **抖音 / 小红书 / 视频号平台内部数据**
   - 不登录拿不到实时播放量、完播率、互动率
   - 拿不到"今天抖音某词搜索量比昨天涨 X%"

2. **100% 爆款预测**
   - 没有任何算法能 100% 预测爆款
   - 只能提高命中率

3. **跳过平台推荐机制**
   - 抖音算法是黑盒，工作流是"输入侧"优化
   - 不能控制"分发侧"

## 📈 如何把命中率从"随缘"提升到"模式化"

工作流做的事情：

1. **复制爆款模式**：知识库 / 提示词 那 2 条 1 万+ / 8000 播放的视频，特征已经被拆解（见 `references/script-blueprint.md` 知识库爆款原版）
2. **新选题按爆款特征清单打分**，重合度高的优先选
3. **每周 3 条覆盖 3 种类型** —— 总有 1-2 条能蹭到热点
4. **持续跑 4-8 周**，根据实际播放数据回测，调整打分权重

## 🔧 边界

- 不登录平台（API 风控）
- 不爬虫
- 不改账号 / 不发布
- 不做抖音内部数据采集
- 用 web_search 公开数据 + 历史爆款特征匹配做选题

## 🎯 爆款特征清单（拆解自知识库 / 提示词爆款）

**知识库爆款（1 万+）特征**：
- 关键词 = 高搜索量（"AI 工具"、"个人知识库"、"AI 教程"）
- 钩子 = 反问 + 具体名词（"使用 AI 的第一步是干嘛？个人知识库"）
- 主体 1 = 直接给答案（"个人知识库"）
- 主体 2 = 可截图的步骤（GitHub 找 → 选 → 更新）
- 收尾 = 低门槛建议 + 提示收藏
- 4 少年中至少 3 个出镜
- 屏幕特写 = 电脑屏幕（GitHub / 工具截图）

**提示词爆款（8000）特征**：
- 关键词 = "提示词"、"AI 提示词"、"提示词工程"
- 钩子 = 反问（"为啥你的 AI 答不对"）
- 答案 = 方法论（限定范围 / 给场景 / 给条件）
- 证据 = 3 组对比截图
- 建议 = 直接抄

**vibecoding 系列（流量低）反特征**：
- 情绪梗 / 段子
- 没有具体名词 / 没有可截图步骤
- 没有证据（无屏幕特写）

## 📊 期望命中率

- **每周 3 条**：按算法模型，**1-2 条预期能进 1000+ 播放**
- **每月 12 条**：**3-4 条预期能进 5000+ 播放**
- **每季度 36 条**：**1-2 条可能进 1 万+ 播放**

实际命中率取决于：
- 账号权重（粉丝 159 是低粉账号，初期流量上限较低）
- 拍摄质量（真实感 > 精致）
- 发布节奏（每天 1 条 vs 每周 3 条 vs 一次性发 3 条）
- 平台政策变化

## 🛠️ 如何回测 + 调权重

每 4 周做一次回测：
1. 把当月发的 12 条视频按播放量排序
2. 高播放的话题在打分表里 +1 分权重
3. 低播放的话题在打分表里 -1 分权重
4. 更新到 `references/script-blueprint.md` 爆款特征清单
