# 决策规则（什么时候停下来问用户）

## 强制停下来问

### 1. 选题阶段

- 候选话题 ≥ 5 个 → 用 `request_user_input` 多选，让用户挑 1-3 条
- 候选话题 0 个 → 重扫一次，仍为 0 时问用户是否放宽赛道
- 候选话题 1 个 → 直接问用户是否采用

### 2. 脚本生成阶段

- 已经写完一条脚本 → 问用户是否要调整字段
- 用户说"改一下" → 不要直接改，按 blueprint 重新生成完整版

### 3. 保存阶段

- 写完所有脚本 → 问用户是否保存到项目
- 用户说"先不存" → 把脚本放在对话里，不动项目

### 4. 边界场景

- 选题命中"已有视频高度重合" → 问用户是接着做还是换选题
- 脚本超出 4 个少年 / 30s → 问用户是否放宽条件
- 选题不在 AI 工具赛道 → 问用户是否破例

## 不要停下来问

- 选题评分 < 10 分的 → 直接淘汰，不告诉用户
- 评分 10+ 但用户没选 → 不要再推荐
- 5 秒级字幕设计 → 按 blueprint 直接生成
- 标签模板 → 按账户画像里的规范直接套
- 标题模板 → 按 6 种模板直接生成

## 决策 SOP

1. **遇到模糊**：先列 2-3 个选项让用户单选
2. **遇到不确定**：先报告具体不确定点，让用户判断
3. **遇到建议**：先给出建议 + 理由，让用户决定
4. **遇到执行**：默认执行，除非用户明确说"先别"

每条都说清楚**为什么**这么选 / 不这么选。
