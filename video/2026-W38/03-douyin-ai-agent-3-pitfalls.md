# 视频 3：抖音 AI 创作 Agent 怎么用？一定要避开 3 个坑！
**拍摄日：9/6 周日 | 时长 30s**

---

## 一、场景 & 角色

- **场景**：教室，4 个少年坐一排 + 1 台电脑
- **A**：戴银眼镜少年（主答）
- **B**：白衬衫少年
- **C**：彩虹衣领少年
- **D**：蓝球衣少年
- **拍摄者**：画外音，不出镜

---

## 二、台词（问答式拍摄）

> 念法：拍摄者提问，少年接力回答，一个坑一个人说。

```
拍摄者：抖音 AI 创作 Agent 怎么用？

A：先避 3 个坑。
A：坑 1，上来就让它干大活，AI 容易跑偏。
（切电脑屏幕：抖音 AI 创作 Agent 界面 + 红字警示）

拍摄者：还有呢？

B：坑 2，提示词写"帮我做个视频"，太泛。

拍摄者：第 3 个？

C：坑 3，做完不检查，直接发。

拍摄者：那应该怎么用？

D：避坑 3 件事：从小活开始 + 写具体要求 + 人工复看。
D：抖音这个 Agent 一直在更新，记得常用。
（手比心）
```
